# 💡xiaoMing · 艾利尔芬特

> 可以用语音控制的智能灯箱
>
> _Author: @Hugokkl_

一款基于 **ASRPRO** 语音识别主控 + **WS2812** RGB 灯带打造的智能语音灯箱。

除了基础的语音调色、亮度调节、场景模式之外，还通过 [HOPE-Remote](https://github.com/ZhangKeLiang0627/HOPE-Remote) 遥控码学习/复现板扩展了 **红外学习发射** 与 **433MHz 无线学习发射** 能力：用嘴就能控制空调、氛围灯、桌灯、大灯等家居电器。

> 红外与 433 已**合并到同一个串口（Serial1）**，由指令中的槽号区间区分介质，不再占用两个 UART。

## 功能特性

### 灯箱控制（WS2812）

- **多色灯光**：红 / 蓝 / 绿 / 黄 / 白 / 紫 / 橙 / 青 / 粉 / 暖光 / 夜灯
- **亮度调节**：亮一点 / 暗一点 / 正常 / 最高 / 最低（亮度范围 10-255）
- **场景模式**：日出、下午茶、阅读、睡眠（睡眠模式附带 30 分钟定时自动关灯）
- **彩虹模式**：彩虹流动动画，一句「吃掉彩虹」随时停止

### 语音交互

- **3 个唤醒词**：`柯南同学`、`艾利尔芬特`、`小明`
- **音量调节**：大声点 / 小声点 / 最大 / 最小 / 正常

### 红外遥控（Serial1 @115200 → HOPE-Remote，槽 000-021）

- **空调**：开 / 关，以及 21-25℃ 五档温度
- **氛围灯**：开 / 关 / 亮度 / 9 色切换 / 流水模式
- 支持**任意红外指令**的学习与发射

### 433MHz 无线遥控（Serial1 @115200 → HOPE-Remote，槽 100-107）

- **桌灯**：开 / 关 / 亮一点 / 暗一点 / 变暖 / 变冷
- **大灯**：开 / 关
- 支持**任意 433 指令**的学习与发射

## 硬件连接

| ASRPRO 引脚 | 功能 | 连接 |
| --- | --- | --- |
| PA2 | Serial1 TX（115200） | → HOPE-Remote PA10（USART1_RX） |
| PA3 | Serial1 RX（115200） | ← HOPE-Remote PA9（USART1_TX） |
| PA4 | WS2812 DIN | → 灯带数据脚 |
| 5V / GND | 电源 | → 灯带 & HOPE-Remote |

> 串口波特率为 **115200**（8N1）。PA2/PA3 需与对端**交叉**连接，GND 必须共地。

## 串口协议

红外与 433 **统一走 Serial1（PA2/PA3）**，以 **115200 8N1** 对接 [HOPE-Remote](https://github.com/ZhangKeLiang0627/HOPE-Remote) 的串口 CLI（对端 USART1）。指令为 **ASCII 文本行**：

| 前缀 | 含义 |
| --- | --- |
| `xx` | 进入**学习**模式（学习对码后写入 Flash 槽） |
| `fs` | **发射**槽内已学习的码 |

**帧格式**：`xx` 或 `fs` + **3 位十进制槽号** + `\r\n`，固定 7 字节。槽号本身就是介质路由：

| 槽号 | 介质 | 本工程占用 |
| --- | --- | --- |
| `000` - `095` | 红外 IR | `000` - `021` |
| `096` - `099` | 保留无效区 | 不使用 |
| `100` - `611` | 射频 433 | `100` - `107` |

> ⚠️ 帧尾 `\r\n` **不可省略**。HOPE-Remote 的 CLI 以 `\r` 或 `\n` 作为行结束符才触发解析，缺少终止符的指令只会滞留在对端的接收缓冲里不执行（旧协议是 4 字节裸串 `xx00`，不符合新协议）。

**示例**：

```text
xx000\r\n   → 学习「打开空调」到红外槽 000
fs000\r\n   → 发射红外槽 000
fs006\r\n   → 发射「空调 21 度」
xx020\r\n   → 学习「氛围灯流水」到红外槽 020
xx100\r\n   → 学习「打开桌灯」到射频槽 100
fs107\r\n   → 发射「关闭大灯」
```

> 射频回放使用 `fsNNN` 的默认参数：**8 帧 × 1 簇，帧间隔 5ms、簇间隔 300ms**（HOPE-Remote 侧实测通杀参数），重复发送由对端负责，本固件只发一次指令。需要短按 / 长按效果时，可在对端改用 `fssNNN`（3 帧）/ `fslNNN`（15 帧）。

> 对端会在每次学习/发射后回一行结果（如 `REC 000 OK`、`FS 000 OK`），当前固件为单向发送、不解析回包，仅便于单独接线调试。

## 开发 & 烧录

1. 安装 **天问 Block（ASRPRO）** 开发环境。
2. 打开 `Firmware/xiaoming.hd` 工程。
3. 在工程内调整唤醒词、命令词与 `ASR_CODE()` 分支逻辑。
4. 编译并下载到 ASRPRO 主控（ASRPRO 板载下载/串口烧录）。

> 语音识别逻辑与工程配置（唤醒词、命令词、回复语）均在 `setup()` 中通过 `{ID:xx, keyword:"...", ASR:"...", ASRTO:"..."}` 注释定义，由 IDE 解析为语音模型。

## 已知问题 & 待办

1. **回家模式 / 出门模式**（`case 177/178`）：尚未实现，`case 178` 仅有注释 TODO。
2. **红外学习是阻塞操作**：HOPE-Remote 的 `xxNNN`（红外）会一直阻塞在采集循环里，直到录到边沿或超时。说「学习…」后需立刻对着 HOPE-Remote 的接收头按原遥控器。
3. **不回读对端回包**：本固件只发不收，`Serial1`（PA3）当前未解析对端返回的 `REC/FS xxx OK`。若要上报「学习成功/失败」，需增加行接收解析。
4. **433 发射档位固定**：目前统一用 `fsNNN` 默认参数（8 帧 × 1 簇）。若某个目标设备需要短按或长按时序，需改发 `fssNNN` / `fslNNN`，可在 `RM_TABLE` 中按指令区分。
